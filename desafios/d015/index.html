Estudando Grid Layout

Grid - grid o uso do grid é organização de itens em duas dimensões (grade).

Container e item: assim como no flexbox, essa distinção é fundamental. Primeiro você deverá possuir um grid container. Os filhos diretos do container são grid items.

Estruturado grid primeiro é importante definir a estrutura do grid (quantas colunas, quantas linhas?) grid-template-columns: define a largura das colunas (exemplo: 100px 1fr 2fr;) grid-template-rows: define a altura das linhas (exemplo: auto 200px repeat(2, 100px);) gap: espaçamento

Posicionamentobásico Os itens se posicionam automaticamente por padrão grid-column: posicionamento em relação às colunas grid-row-posicionamento em relação às linhas
